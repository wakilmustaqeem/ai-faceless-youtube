# YouTube / Google Documentary Compliance Plan v1

Date: 2026-09-23
Project: AI & IT Future Tech
Format: 15–30 minute long-form documentary
Master language: English
Public publishing: OFF; YouTube upload remains manual
Human approval: REQUIRED

## Objective
Bring the long-form documentary pipeline to a review-ready state aligned with current YouTube/Google monetization, originality, rights, AI-disclosure, safety, and metadata requirements.

## Locked implementation order
1. YouTube Compliance Gate v1
2. Rights / Asset Provenance Manifest
3. Originality + Reused/Mass-Production Gate
4. AI Disclosure Metadata Gate
5. Community Guidelines / Advertiser-Suitability pre-check
6. Title / Description / Thumbnail QA
7. Final Private-Review Gate
8. Human approval
9. Manual YouTube upload only

## Required documentary flow
Verified Research
→ Evidence
→ Long-form Script
→ Originality Check
→ Rights/Provenance Check
→ AI Disclosure Check
→ Community/Advertiser Pre-check
→ Girl/Boy Voice QA
→ Visual QA
→ Caption QA
→ Metadata QA
→ Human Review
→ Private Upload
→ Final Human Approval
→ Manual Public Upload

## Non-negotiable safeguards
- No article/video generation from unverified evidence.
- No public auto-publishing.
- No YouTube credentials/API connection.
- Every visual/audio asset must have source, rights/license status, and commercial-use status where applicable.
- Documentary substance must be materially original and not mass-produced/repetitive.
- Realistic altered/synthetic content must carry the required AI disclosure metadata.
- Human review remains mandatory.
- Compliance failure is fail-closed.

## Current state
- Long-form documentary spec: implemented.
- Natural young adult Girl/Boy voice profiles: implemented.
- Episode schema + validator: implemented.
- Source-verified documentary package builder: implemented.
- Public YouTube publishing: disabled.
- Remaining work: compliance gates, asset provenance, originality/anti-mass-production checks, AI disclosure metadata, safety/advertiser pre-check, metadata QA, final private-review gate.

## Acceptance condition
Do not mark the documentary system monetization/compliance-ready until all gates above pass on a real source-verified episode and the final MP4/package passes human review.
