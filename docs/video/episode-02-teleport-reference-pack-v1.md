# Episode 2 — Teleport Reference Pack v1

## Purpose
Provider-neutral reference checklist for the first 2027 Time Bridge contact.

## Canonical references

- R01 — 2040 presenter: approved full-body human reference.
- R02 — 2040 classroom: exact three fixed-display geometry.
- R03 — 2027 creator: young realistic human creator reference.
- R04 — 2027 environment: period-correct room and technology.
- R05 — Racing Game prototype: consistent visual identity.
- R06 — Time-Travel Application: destination-selection UI.
- R07 — Teleport signature: white/golden burst, controlled particles, subtle distortion and motion blur.
- R08 — Arrival plate: matching body position, footing and environment interaction.

## Hard rejects

- fantasy portal
- giant wormhole
- cartoon/CGI character
- plastic/AI-avatar face
- floating classroom displays
- identity drift
- wardrobe drift
- unexplained 2040 hardware in 2027
- teleport without destination UI
- teleport without light signature
- violent/horror treatment
- history-rewrite implication

## Approval gate

No generated video becomes a canonical reference until the human owner approves the reference image/keyframe.

## 3-second prototype target

0.0–0.7s stable full-body presenter
0.7–1.4s controlled light build
1.4–1.8s peak burst + disappearance
1.8–2.3s transition/clean plate
2.3–3.0s arrival burst + natural materialization

## Production rule

Generation provider may change. Character identity, classroom geography, teleport signature and destination UI may not change.
