# Episode 2 — Teleport Prototype QA Checklist v1

## Technical
- [ ] FFmpeg is available locally.
- [ ] Three approved still references exist.
- [ ] Output is 9:16.
- [ ] Output plays from start to finish.
- [ ] No missing-frame or broken-overlay artifacts.
- [ ] Frame rate is stable.

## Visual continuity
- [ ] Same presenter identity at departure and arrival.
- [ ] Same wardrobe.
- [ ] Same body proportions and camera relationship.
- [ ] Departure footing is natural.
- [ ] Arrival footing is natural.
- [ ] 2027 destination plate is readable.
- [ ] No floating displays.
- [ ] No portal/wormhole aesthetic.

## Teleport signature
- [ ] White/golden burst begins before disappearance.
- [ ] Burst peaks at disappearance.
- [ ] Controlled particles/distortion only.
- [ ] Destination screen updates during transition.
- [ ] Matching arrival burst.
- [ ] Presenter progressively materializes.

## Editorial
- [ ] Reads as friendly technology/mystery.
- [ ] No horror sting.
- [ ] No history-rewrite implication.
- [ ] No paid generation dependency.
- [ ] Human owner approval recorded before canonical use.

## Evidence rule
A PASS requires an actual rendered file plus visual inspection. Documentation alone cannot mark the prototype rendered or approved.
