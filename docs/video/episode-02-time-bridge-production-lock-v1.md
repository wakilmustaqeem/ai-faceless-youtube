# RACING GAME — TIME-TRAVEL UNIVERSE
## Episode 02 — THE FIRST CONTACT — Production Lock v1

## Purpose
Episode 2 begins immediately after Episode 1's UNKNOWN SOURCE: 2027 cliffhanger. The 2040 classroom discovers that the LEGACY CORE signal is not a normal network message. The Time-Travel Application identifies 2027 as a reachable destination.

The full time-travel truth is revealed through action, not exposition.

## Target format
- Vertical 9:16.
- Chinese-style cinematic micro-drama pacing.
- Short controlled shots.
- Strong opening continuation from Episode 1.
- Human performances and natural movement.
- Story-first visual effects.
- Manual human review before publication.

## Continuity
Carry forward:
- same 2040 classroom;
- same presenter;
- same student group;
- same three fixed LCDs;
- same master mobile;
- same racing game;
- same LEGACY CORE interface;
- same realistic cinematic visual language.

## Story sequence

### Shot 01 — The Signal Returns
The black screen from Episode 1 returns to the 2040 classroom.

Center LCD:
LEGACY CORE — ACCESS LIMITED

Then:
UNKNOWN SOURCE: 2027

Presenter quietly asks:
“Why 2027?”

### Shot 02 — Application Takes Control
The presenter opens the Time-Travel Application on the master mobile.

Interface:
SOURCE YEAR: 2027
DESTINATION AVAILABLE

Students move closer naturally.

### Shot 03 — Year Selection
Presenter selects:
2027

The application runs:
ERA SCAN — 2027
DESTINATION: READY

### Shot 04 — First Teleport
Presenter confirms the destination.

Canonical sequence:
YEAR SELECT → DESTINATION CONFIRM → BRIGHT LIGHT BURST → DISAPPEARANCE

A short, powerful white/golden flash surrounds the presenter. He disappears at the peak.

### Shot 05 — Arrival
A genuine 2027 environment appears, appropriate to the story location.

Matching light burst appears. Presenter materializes naturally.

Screen:
NEW WORLD
then:
YEAR: 2027
ERA: PAST

### Shot 06 — First Contact
Presenter sees a young student/creator working on an early racing-game project.

The two notice each other. Curious and friendly, not threatening.

### Shot 07 — Racing Game Connection
The 2027 creator's screen contains an early version of the racing game.

The 2040 presenter recognizes the architecture. The same steering concept is visible. A small matching signal appears on both devices.

### Shot 08 — Friendly Talent Exchange Begins
Presenter demonstrates one modern debugging concept. The 2027 creator demonstrates an original design idea.

The exchange is collaborative.

Theme:
Technology can move across time. Talent already exists in every generation.

### Shot 09 — Glitch
The application warns:
TIME BRIDGE INSTABILITY

Return control becomes temporarily unavailable.

No horror. No violent effect.

### Shot 10 — Cliffhanger
A second source identifier appears:
LEGACY CORE
ORIGIN: 2027

Then:
NEXT CONTACT: ???

CUT TO BLACK.

## Teleportation rule
All major Episode 2 teleportation uses the permanent signature in the Time-Travel Teleportation Production Lock.

Departure:
- bright white/golden light burst;
- controlled particles;
- subtle distortion;
- synchronized whoosh;
- clean disappearance.

Arrival:
- matching light burst;
- light contracts toward traveler;
- natural full-body materialization;
- correct footing;
- immediate environment interaction.

Screen:
NEW WORLD
then actual YEAR / ERA / LOCATION.

## Production method
Generate/assemble short controlled shots rather than relying on one long generative take.

Priority:
1. approved character references;
2. approved environment references;
3. controlled image-to-video or local generation;
4. local compositing for teleport light;
5. local edit and sound;
6. continuity QA;
7. human owner review.

Do not claim local generative rendering is ready until the actual production-machine preflight passes.
