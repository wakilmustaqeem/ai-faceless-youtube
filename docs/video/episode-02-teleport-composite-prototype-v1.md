# Episode 2 — Teleport Composite Prototype v1

## Goal
Build the first 3-second teleport shot without paid generation.

## Pipeline
START KEYFRAME
→ subtle camera motion
→ controlled white/golden light burst
→ disappearance mask
→ short transition plate
→ destination UI update
→ arrival light burst
→ progressive materialization
→ natural footing

## Timing
- 0.0–0.7s: presenter stable; minimal breathing/weight shift.
- 0.7–1.4s: light intensity builds around the presenter.
- 1.4–1.8s: peak burst; presenter disappears behind mask/bloom.
- 1.8–2.3s: clean transition; destination UI becomes visible.
- 2.3–3.0s: matching arrival burst; presenter materializes naturally.

## Free-first implementation
Use still reference/keyframes plus local FFmpeg/Remotion motion, masks, glow, particles and sound. No paid AI generation is required for this prototype.

If free I2V access is later available, it may replace the camera-motion section while preserving the same composite and QA contract.

## Hard visual rules
- no fantasy portal
- no giant wormhole
- no cartoon/CGI look
- no identity drift
- no wardrobe drift
- no camera teleport
- no floating displays
- destination screen must identify the selected year
- departure and arrival light signatures must match
- sound must rise on departure and resolve on arrival
- human approval required before canonical use

## Acceptance
PASS only if the shot reads as one continuous live-action teleportation event and preserves character identity, destination UI continuity and physical footing.
