## Session Rule
Future students may receive temporary access to a module, object or Time Gate. At session end, access is revoked unless Mustafa explicitly extends it.

## Emergency Rule
If a transfer or update threatens timeline continuity, the Time Bridge enters LOCK state and all limited sessions freeze.
