Same recurring group of 10–12 diverse international students, seated/standing naturally in a neutral studio-classroom reference setup, each face clearly visible, consistent age range, realistic proportions, natural expressions, ordinary modern clothing suitable for a premium 2040 classroom, neutral lighting, no exaggerated poses, no text, no logos.

Premium international 2040 classroom, front-wall perspective, exactly three permanently installed physical displays: one huge center wall display, one smaller fixed left LCD angled inward, one smaller fixed right LCD angled inward. Straight-on architectural continuity reference of the front wall. Center display clearly largest. Left and right LCDs physically mounted and slightly angled inward toward students. ## Asset 06 — Master Mobile Reference
Premium thin handheld master control device, realistic physical object, front and rear views, consistent dimensions, subtle future interface, no sci-fi hologram projection, no branding, neutral studio lighting, isolated background.

## Asset 07 — Racing Game UI Reference
Racing game interface designed for the classroom displays: central 3D track, vehicle telemetry, steering/input flow, lap timer, student session state. Premium technical UI, restrained luminous accents, high readability, physically displayed on LCD panels, no floating HUD outside screens, no copyrighted game branding.

## Asset 08 — Mystery UI Reference
Minimal diagnostic interface for the final Episode 1 reveal. Black/neutral technical background, restrained warning accent, exact strings:
LEGACY CORE — ACCESS LIMITED
UNKNOWN SOURCE: 2027
The mystery UI must feel like an authentic system diagnostic, not horror or fantasy. No skulls, glitch horror, cyberpunk overload, or unexplained symbols.

## Approval Gate
Do not animate Episode 1 until Assets 01–08 pass:
- identity match;
- wardrobe continuity;
- classroom geometry;
- screen count = exactly three;
- master mobile continuity;
- UI readability;
- no unwanted logos/text;
- no floating-screen behavior.

## Reference Integrity Rule
The canonical reference is the approved source, not a derived video frame. If a generated shot drifts, return to the canonical reference instead of using the drifted frame as the new reference.
