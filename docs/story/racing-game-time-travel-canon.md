# Racing Game — Time-Travel Canon v1

## Core Canon

- **Original Creator:** Mustafa
- **Age in 2027:** 18
- **Status in 2027:** Matric student
- **Role:** Original creator / Root authority of the Racing Game APK
- **Secret:** Mustafa alone holds the hidden **Time-Travel Core / Root Key**.

The Racing Game is not merely a racing game. The APK is the interface for a hidden time-travel system.

## Timeline

- **2027:** Mustafa, 18, creates the original Racing Game APK.
- **2040:** A future classroom receives limited access and updates authorized modules.
- **2090:** A later generation uses an evolved version and can connect through the Time Bridge.

## Time Bridge

The Time Bridge creates controlled, friendly connections between eras.

It is primarily used for:
- knowledge exchange
- talent exchange
- product exchange
- technology exchange
- collaborative problem solving

**Continuity rule:** the bridge does not casually rewrite history. Transfers are controlled by access level, authorization and quantity limits.

## Access Hierarchy

### ROOT — Mustafa
- Full creator authority.
- Holds the Secret Core / Root Key.
- Controls which modules, objects and eras can be accessed.
- Does not reveal the entire secret at once.

### LIMITED — Future Team / 2040
- Can operate approved Racing Game modules.
- Can update authorized game systems.
- Can open authorized Time Gates.
- Cannot read, copy or independently unlock the Secret Core.

### EVOLVED — 2090
- Can use later-generation modules and send/receive authorized messages.
- Has more advanced technology but still does not automatically possess Mustafa's Root Key.

## Time Commerce

### Future → Past
Mustafa can bring selected future-origin:
- technology
- tools
- devices
- designs
- materials

into the past in limited quantities for controlled sale or exchange.

### Past → Future
Mustafa can send selected past-origin:
- handmade products
- original designs
- ideas
- creative methods
- human talent

into the future for development, exchange and new value.

This two-way exchange is a major story engine.

## Story Engine

`UPDATE → ACCESS LEVEL → TIME GATE → ERA → PERSON/PRODUCT → MISSION → CONSEQUENCE → NEW LOCKED MYSTERY`

Every limited-access update can create a new story branch while preserving continuity.

## Core Mystery Progression

1. Future students think they are only updating a racing game.
2. They discover a hidden Legacy Layer.
3. The Legacy Layer reveals the Time-Travel Core.
4. They discover the Root authority belongs to Mustafa.
5. They realize Mustafa created the system while still an 18-year-old Matric student in 2027.
6. Future-origin and past-origin objects begin revealing controlled causal loops.
7. The 2090 generation appears to be participating in the same time-commerce network.
8. The Creator-only market becomes the next locked mystery.

## Production Identity

- Chinese-style vertical cinematic micro-drama.
- Native 9:16.
- Realistic full-body human characters.
- Natural movement, voice, blinking and reactions.
- Premium believable future technology.
- Real classroom.
- Three physically fixed displays: one large center display plus fixed left/right angled LCDs.
- Presenter master mobile.
- Hand + voice control.
- Individual student devices and permission gates.
- No cartoon, avatar, cheap cyberpunk, floating-screen fantasy or slideshow-only aesthetic.

## QA Rules

Reject any scene that:
- changes Mustafa's 2027 age/origin;
- gives Future Team unrestricted Root access;
- reveals the Secret Core without an explicit story event;
- casually rewrites history;
- violates the Time Bridge transfer limits;
- changes the fixed three-display classroom geometry;
- breaks recurring character or prop continuity.

## Theme

**Technology travels forward.  
Talent travels backward.  
Mustafa connects both.**
