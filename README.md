# AI Faceless YouTube

Independent, governance-first faceless YouTube automation system.

Working brand: AI & IT Future Tech
Tagline: AI, IT & the Future of Technology

The channel is English-first and covers AI, IT, future technology, recent technology developments and practical technology explainers. Approved English masters are designed for localization into all languages supported by the active translation provider.

HidayatTube is only a reference for engineering patterns. HidayatTube branding, content, credentials, channel identity, history and production data are not copied or connected.

Pipeline: Research -> Script -> Originality Gate -> Voice -> Visuals -> Edit -> QA -> Localization -> Private Review -> Human Review -> Publish/Reject

Rules: separate YouTube/Google identity and credentials; no secrets in source control; public publishing is human-review gated and OFF by default; destructive or production actions require explicit approval; material actions are auditable; free/open-source providers are preferred; provider connectivity must be verified before activation.

Status: independent brand + localization architecture implemented. Production publishing remains OFF until provider, channel and human-review verification are complete.
