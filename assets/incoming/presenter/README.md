# Presenter Upload Folder

Upload the Meta-generated full-body presenter image in this folder.

## Expected source
- Photorealistic full-body presenter, head to toe.
- PNG preferred; JPG/JPEG accepted.
- No watermark, text, logo, or unintended people.
- Keep the original source image unchanged.

## QA flow
1. Upload the source image here.
2. Do not overwrite `assets/presenter-verified.png`.
3. The image will be checked for full-body visibility, face/hands/anatomy, clean silhouette, watermark/text/logo absence, and compositing suitability.
4. Only after QA approval will a separate verified production asset be created.

This folder is an incoming source area, not the verified production asset.
